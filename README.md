# Plan InPlace

Create a plan and store it with your project. Manage tasks with kanban, table, and more.
- Offline Data: Plan data is stored locally in your designated folder (e.g. your project folder).  
- No Setup: Simply track your plan together with your project folder using Git or any cloud services you like.
- AI-Friendly: Data is stored in JSON. To generate a plan for a project using AI, simply use your project folder and the Plan InPlace templates as the context, ask your agent to create a plan in JSON and open it in Plan InPlace.
